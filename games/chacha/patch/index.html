한글패치 다운로드

이야기 대사, 타이틀, 세이브 메뉴와 슬롯, 전투·소지품·상태 메뉴, 기술·아이템 이름과 설명을 한국어로 바꿨습니다.

브라우저에서 패치 적용한글패치 다운로드 · GitHub한국어 공략 보기오류 제보

설치 없이 브라우저에서 적용

  1. 브라우저 패치 적용 화면을 엽니다.
  2. 헤더 없는 일본판 원본 .sfc 또는 .smc를 선택합니다.
  3. 한글 ROM 만들기 → 한글 ROM 저장을 누릅니다.
  4. 내려받은 .sfc를 에뮬레이터에서 엽니다.

Windows·macOS·Linux에서 Python 설치나 명령어 입력 없이 사용할 수 있습니다. ROM은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 원본·패치·완성 ROM의 크기와 SHA-256을 자동 확인합니다.

오프라인 적용과 Windows 배치 파일

easy.zip 다운로드 후 압축을 풉니다.

  • Windows: apply-patch.bat을 더블클릭하면 브라우저 적용 화면이 열립니다. PowerShell 명령이나 Python 설치는 필요 없습니다.
  • macOS·Linux: apply-patch.html을 브라우저에서 엽니다. 편집기로 열리면 ‘연결 프로그램’에서 브라우저를 선택하세요.

원본 선택 → 한글 ROM 만들기 → 한글 ROM 저장 순서로 진행합니다. 패치가 HTML 안에 포함돼 있어 인터넷 연결 없이 사용할 수 있습니다.

BPS·xdelta 적용 프로그램

SFC ROM에도 xdelta를 적용할 수 있습니다. ZIP의 patches/에서 .bps 또는 .xdelta 하나를 골라 일본판 원본에 적용하고 새 .sfc 파일로 저장하세요. 두 형식 모두 같은 한글판을 만듭니다. 같은 원본에 두 패치를 차례로 적용하지 마세요.

명령줄 적용법은 저장소 안내에서 확인할 수 있습니다.

플레이와 저장

슈퍼패미컴 실기에서는 확인하지 않았습니다.

에뮬레이터는 Mesen Community Edition 2.2.1을 사용할 수 있습니다. 기존 저장은 백업하고 일반 저장(SRAM)을 새 ROM 이름에 맞춰 연결하세요. 다른 버전의 강제저장·세이브스테이트는 사용하지 말고 새 게임 또는 일반 저장으로 시작하세요.

제작·글꼴·재배포

번역·식자: 러브델릭(엔스헨데)

  • DOSSaemmul / DOSPilgi — leedheo. 보통체·굵은체·낙서체에 사용했습니다.
  • Dalmoori(달무리) — RanolP. 세이브 메뉴·슬롯의 작은 글자에 사용했습니다.

게임에 맞춰 래스터화·폭/위치·일부 획을 보정했습니다. 글꼴 출처와 라이선스 고지는 저장소와 ZIP에 포함되어 있습니다.

출처와 버전을 표시하면 패치 재배포를 허용합니다. 최신 파일과 적용 안내를 받을 수 있도록 공식 배포 주소 공유를 권장합니다.

게임 ROM은 제공하지 않습니다. 게임·캐릭터의 권리는 각 권리자에게 있으며 공식 제작사와 관계없는 팬 패치입니다.
