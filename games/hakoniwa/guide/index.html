울타리·가구 배치 강좌

이 게임에서 제일 먼저 알려줬어야 하는 조작들.

패드 기본 조작 기준. 키 설정을 바꿨다면 같은 기능에 지정한 버튼을 사용하세요. PC 키보드에서는 게임 중 F1로 조작표를 확인할 수 있습니다.
🎯

B 길게 — 배치 마커

물건을 내려놓기 전에 실제로 놓일 위치를 마커로 확인합니다. 울타리나 가구를 정렬할 때 가장 먼저 써야 하는 기능입니다.

↻

L + X — 들고 있는 물건 회전

물건을 들고 있는 상태에서 방향을 바꿉니다. 내려놓았다가 다시 집을 필요가 없습니다.

🔄

L + A — 놓은 물건 회전

눈앞에 놓인 가구나 울타리의 방향을 그 자리에서 바꿉니다. 식물처럼 땅에서 자라는 것은 제외됩니다.

✨

도구 ‘없음’ + Y — 정렬 보정

X로 도구를 ‘없음’에 맞춘 뒤 Y를 누르면 눈앞 물건의 어긋남과 기울기를 가지런히 보정합니다.

🧱 울타리를 반듯하게 치는 순서

  1. 기준 울타리 하나를 먼저 놓습니다.첫 조각이 전체 줄의 기준이 됩니다.
  2. 다음 울타리를 들고 B를 길게 누릅니다.배치 마커를 보면서 기준 울타리의 가운데 기둥 부근을 목표로 접근합니다.
  3. 울타리는 사선으로 이어진다는 감각으로 맞춥니다.화면에서 수평·수직으로 딱 붙이는 방식이 아니라, 중심 기둥을 기준으로 사선 위치가 맞아야 자연스럽게 연결됩니다.
  4. 방향이 틀리면 L+X 또는 L+A로 돌립니다.들고 있으면 L+X, 이미 내려놨다면 L+A가 빠릅니다.
  5. 마지막에 도구 ‘없음’ + Y로 한 칸씩 보정합니다.약간 비뚤어진 울타리도 다시 집지 않고 정렬할 수 있습니다.
  6. 모서리와 틈을 마지막으로 확인합니다.아주 작은 동물은 틈을 빠져나갈 수 있으므로 애매한 공간은 말뚝·통나무·장식돌 등으로 막아 주세요.

1고정 건물 동선 확보집·저장고·사육장으로 가는 길부터 비워 둡니다. 이 길을 장식이나 보관대로 막지 않습니다.
2주통로를 먼저 정하기목장 가운데를 가로지르는 이동로를 먼저 확보합니다. 나중에 가축이 늘어도 사람이 지나갈 길은 남아 있어야 합니다.
3가축 우리와 출입구 만들기울타리부터 반듯하게 친 뒤, 키울 동물에 맞춰 장식돌·깔판·데크 중 출입구를 고릅니다.
4가공시설은 재료 구역 가까이에치즈 선반·와인통·햄 건조함처럼 옆에 재료를 놓아야 하는 시설은 통로를 피하면서 재료 생산 구역 가까이에 둡니다.
5보관대·팻말은 가장자리로이 시설들은 내부에 저장하지 않고 주변에 물건을 모읍니다. 주변 바닥까지 차지하므로 벽이나 가장자리 쪽에 두는 편이 좋습니다.
6작물밭과 유인용 화분 구역 나누기양배추밭과 꽃 화분을 붙여놓지 말고, 나비를 빼낼 화분 구역을 따로 마련합니다.
7장식은 마지막분수·의자·화분 같은 꾸미기 요소는 생활 동선과 생산 구역이 완성된 뒤 남는 공간에 놓습니다.
공간이 모자랄 때 우선 정리할 것 당장 안 쓰는 보관대·팻말 → 순수 장식 → 사용하지 않는 브라미 자동화 → 기술을 이미 배운 사냥상 순으로 정리하면 비교적 안전합니다.

전체 교환 도식

게임 안에서 아직 실루엣으로 가려진 교환도 포함해, 시장 교환 전체를 한눈에 펼쳐 봅니다.

주는 것 → 받는 것“이걸 내면 뭘 받을 수 있지?”를 볼 때
받는 것 ← 필요한 것“이걸 얻으려면 뭘 줘야 하지?”를 볼 때
검색은 필터가 아니라 강조도식은 그대로 두고 관련 항목만 밝게 표시합니다.
