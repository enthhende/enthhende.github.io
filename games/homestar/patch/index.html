xdelta만 모은 ZIP · 약 28.9 MB

별도의 xdelta 적용 도구가 필요합니다. 아래 원본 해시를 확인한 뒤, 사용할 기기에 맞는 xdelta 하나만 원본 ISO에 적용해 주세요.

두 판을 겹쳐 적용하지 마세요

두 판 모두 같은 일본판 원본 ISO에 각각 독립적으로 적용합니다. 기본판 위에 Vita판을 덧씌우지 마세요. 배포 파일에는 원본 ISO나 완성 ISO가 포함되어 있지 않습니다.

ZIP으로 적용하기

인터넷 없이 사용할 수 있는 적용기가 각 ZIP 안에 들어 있습니다. PC에서 진행해 주세요.

  1. 압축 풀기기기에 맞는 ZIP 하나를 받고 완전히 압축 해제합니다. 두 판을 같은 폴더에 섞지 마세요.
  2. 적용기 열기Windows는 apply-patch.bat, macOS·Linux는 apply-patch.html을 엽니다.
  3. 원본 선택 · 적용일본판 원본 ISO를 선택하고 ‘패치 적용’을 누릅니다. 원본·패치·결과를 검사합니다.
  4. 완성 ISO 저장검사가 끝나면 ‘완성 ISO 저장’을 누릅니다. 저장이 끝난 파일을 기기로 복사합니다.

Python·xdelta3는 필요하지 않습니다. 원본 파일은 바뀌지 않고, ISO를 서버로 전송하지 않습니다. 약 604 MiB의 결과 파일과 브라우저 작업용 메모리, 저장 공간을 확보해 주세요.

받기 전에 알아두세요

두 판의 GPS 차이

기본판은 PSP용 외장 GPS 연동 처리를 유지합니다. 실제 GPS 수신기 동작은 별도로 확인하지 않았습니다. Vita 호환판은 이 연동 처리를 제외했으며, 날짜·시각·관측지를 직접 정하는 기능은 그대로 사용할 수 있습니다. 원작의 공식 Vita 지원을 뜻하지 않습니다.

확인한 환경과 남아 있는 제한

기본판은 PPSSPP와 PSP의 본편·시어터·공유를, Vita 호환판은 Vita·Adrenaline 기동·밤하늘·시어터 전편·사운드 장시간 동작·종료 복귀와 공유를 확인했습니다. PSP 실기 2대의 게임 공유도 확인했습니다.

모든 기기 조합, 실제 GPS 수신기, 기존 일본판 세이브 호환, Vita가 받는 공유나 Vita끼리 공유는 확인하지 않았습니다. 사용 중인 세이브는 먼저 백업해 주세요.

한국어로 바뀐 내용

메뉴, 천체 사전, 시어터 자막, 이미지 속 글자, 게임 공유 수신 프로그램을 한국어로 옮겼습니다. 한글 폰트가 포함되어 있습니다. 일본어 음성, 제작진 이름에 함께 적은 원문과 일부 원본 표기는 남아 있습니다.
