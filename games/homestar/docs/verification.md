# 검증 범위

**기본판과 Vita 호환판 모두 아래에 적은 환경에서 검수를 마쳤습니다.** 공개 패치를 수정하지 않은 지원 원본에 각각 적용한 뒤, 실기에서 확인한 ISO와 전체 크기·SHA256이 같은지도 검사했습니다. 배포 파일을 만드는 과정에서 번역·폰트·게임 코드를 다시 수정하지는 않았습니다.

## 기본판 — PSP·PPSSPP

PSP 실기에서 확인을 마친 151번 후보를 기준으로 정리했습니다.

| 구분 | 확인 내용 |
|---|---|
| PPSSPP | 전 메뉴·천체 사전·검색·설정·메뉴 복귀 확인, 판타지 시어터 장시간 재생 후 최종 검수 |
| PSP 본편 | 한글 표시, 자간·잘림 수정 결과, 시어터 자막 가독성 확인. 시어터 전편 재생 완료. 그 과정에서 멈춤이나 추가로 남은 일본어를 발견하지 못했다는 검수 결과 |
| 폰트 ISO 내장 | 외부 PGF 없이 새로 기동한 에뮬레이터에서 메뉴·자막·사전 확인. PSP에서는 기동·메뉴·자막과 HOME 종료 후 기본 메뉴 복귀 확인 |
| PSP 게임 공유 | PSP 실기 2대로 직접 확인 |

시어터 검수를 마친 뒤에는 자막·글꼴·본편 동작을 그대로 둔 채 공유 파일을 수정했습니다. 마지막으로 바꾼 것은 본편이 폰트를 읽는 경로로, 외부 파일 대신 ISO 안의 파일을 읽도록 했습니다. 이때 공유 수신 파일은 전혀 바꾸지 않았습니다.

앞서 확인한 결과를 이어서 적은 것은 이렇게 내용이 그대로인 부분에 한해서입니다. 마지막 경로 변경 뒤에 시어터 전편과 게임 공유를 처음부터 모두 다시 시험한 것은 아니니, 이 점은 구분해서 봐 주세요.

## Vita 호환판 — Vita·Adrenaline

GPS 관련 처리를 제외한 159번 후보를 기준으로 정리했습니다.

| 구분 | 확인 내용 |
|---|---|
| 기동·밤하늘 | 별도 설정 변경 없이 기동, 밤하늘·시어터 진입, HOME 종료 후 기본 메뉴 복귀 확인 |
| 판타지 시어터 | Vita·Adrenaline에서 모든 영상을 끝까지 재생 |
| 사운드 | 장시간 틀어 두었을 때 문제없이 동작했다는 검수 결과. 곡별 전수 확인이나 정확한 재생 시간 측정까지 마쳤다는 뜻은 아님 |
| 게임 공유 | Vita 호환판에서도 게임 공유 동작 확인 |

번역·폰트·시어터·공유 수신 프로그램은 기본판과 같습니다. 다른 부분은 본편의 GPS 관련 명령 11개이며, 실제로 달라진 데이터는 32바이트입니다. Vita에서도 기동해 밤하늘과 시어터 전편, 사운드 장시간 재생, 게임 공유까지 따로 확인했습니다. 기본판에서 된다는 이유만으로 Vita에서도 된다고 적은 것은 아닙니다.

다만 159번을 PSP에서 실행한 실기 결과와, Vita가 받는 쪽이 되는 공유 조합은 이번 검증 범위에 포함하지 않았습니다.

## GPS와 지원 범위

원작의 당시 안내에는 Vita에서 플레이할 수 없고 PSP만 대응한다고 적혀 있었습니다. 제가 쓰는 Adrenaline 환경에서도 일본판 원본은 검은 화면만 나왔고요. 이후 PSP용 외장 GPS 관련 처리를 제외한 159번으로 실행에 성공해 위에 적은 내용을 확인했습니다. 이번 호환판에서 확인한 결과이며, 원작이 공식적으로 Vita를 지원하게 된 것은 아닙니다. [세가의 2012년 다운로드판 안내문](https://www.4gamer.net/games/065/G006599/20120719062/)

기본판은 기존 GPS 연동 처리를 그대로 두었습니다. Vita 호환판에서는 외장 GPS로 위치를 자동으로 받아올 수 없지만, 날짜·시각·관측지를 직접 설정하는 기능은 남아 있습니다. 실제 GPS 수신기의 동작과 기존 일본판 세이브를 이어 쓰는 경우는 별도로 확인하지 않았습니다.

여기에 적은 실기 결과는 제가 시험한 기기와 실행 환경에서 확인한 내용입니다. 모든 기기 모델과 환경의 조합을 시험하지는 못했습니다. 다른 환경에서 문제가 생긴다면 사용한 배포판과 실행 환경을 함께 적어 제보해 주세요.

## 패치 파일 검증

두 xdelta 파일은 각각 같은 지원 원본에 적용해 해당 판의 ISO를 만드는 독립 패치입니다. 원본, 선택한 패치, 적용 결과의 전체 크기와 해시를 차례로 검사하도록 했습니다. 실제 배포 ZIP을 새 폴더에 풀고 동봉된 적용기로 원본에 다시 적용해, 각 결과가 실기에서 확인한 ISO와 완전히 같은지도 확인했습니다. 잘못된 원본이나 손상된 패치를 넣었을 때, 기존 출력 파일을 덮어쓰려고 할 때, 도구가 실패하거나 작업이 중단될 때의 처리도 검사했습니다.

공개 저장소 소스의 기본 manifest는 PSP판이며, Vita판의 manifest는 `profiles/vita.json`에 함께 두었습니다. 다운로드 ZIP에는 해당 판의 manifest가 `manifest.json`이라는 이름으로 들어 있어서 같은 적용기를 그대로 쓰면 됩니다. 두 배포 ZIP을 한 폴더에 섞어 풀거나, 한쪽 패치 위에 다른 쪽을 덧씌우지 말아 주세요.

브라우저 적용기도 같은 xdelta를 사용합니다. 원본 ISO를 두 판에 각각 실제 적용하고, 브라우저에서 저장한 결과 전체가 151·159 성공본의 SHA256과 일치하는지 확인했습니다. Chrome에서 오프라인 HTML과 웹 주소로 연 화면을 각각 시험했으며, 잘못된 파일의 거절과 취소 후 재시작도 확인했습니다. Windows 배치파일은 이 HTML을 기본 브라우저로 여는 역할입니다. 실제 Windows에서 배치파일을 여는 시험과 모든 브라우저·메모리 환경의 조합까지 확인한 것은 아닙니다.
